# 주간 콘텐츠 — 원고 한 편에서 나눔지·카드뉴스·에세이·썸네일·쇼릴·업로드 문안까지

사용법: 완성된 설교 원고(.md 또는 .txt) 한 편을 **`원고/` 폴더**에 넣고 `/주간콘텐츠`를 한 번 실행한다. 인자를 주면(`/주간콘텐츠 경로/원고.md`) 그 파일을 쓴다. 원고가 없거나 둘 이상이면 어느 파일인지만 묻고 멈춘다. 원고는 수정하지 않는다. 설교 준비·연구·원고 작성은 이 명령의 범위가 아니다.

산출은 `산출/<원고 파일명>/` 아래에 쓴다. `원고/교회이름.txt`(한 줄)가 있으면 그 교회 이름을 카드·썸네일 하단에 넣고, 없으면 비운다. 다른 상호·브랜드 문구는 기본으로 찍지 않는다. 스킬 안의 `00-원고지도.md`는 1단계 산출을, `교회 정보`는 이 파일(과 사용자가 준 색·예배 시간·SNS)을 뜻한다. 도구 폴더는 `${CLAUDE_CONFIG_DIR:-$HOME/.claude}/sermon-osmu-tools/scripts/`가 있으면 그곳, 없으면 현재 폴더의 `scripts/`다. 아래 `scripts/`는 그 폴더를 뜻하며, 스킬 안의 경로가 팩에 없으면 이 명령의 경로가 우선한다.

## 0. 준비물 점검 (먼저 1회)

`bash scripts/check-tools.sh`를 실행해 `산출/<원고 파일명>/준비물_점검.md`에 저장한다. 준비물이 없는 단계는 **오류가 아니다.** 그 단계의 텍스트 산출은 끝까지 만들고, 이미지·영상·업로드만 건너뛴 뒤 마지막에 「텍스트 산출까지 완료 · 이 단계는 준비물이 없어 건너뜀 (필요: …)」 한 줄을 안내한다. 건너뛴 단계를 완료로 쓰지 않는다.

## 1~8. 순서대로 생성

1. **원고 지도** — 원고 전체를 읽고 SHA-256, 제목, 본문 참조, 핵심 메시지, 청중의 갈등, 복음 전환, 적용을 `00-원고지도.md`에 원문 행과 함께 기록한다. 원문에 없는 요소는 `[미확인]`. 성경 본문 직인용은 사용자가 준 판본 원문만 쓴다.
2. **나눔지** — `small-group/small-group_SKILL.md`와 `small-group/rules/`를 읽고 장년·청년·청소년·초등 나눔지를 각각 `01-나눔지-<대상>.md`(스킬 형식대로 HTML도 가능)로 만든다. PNG 캡처 도구는 팩에 없으므로 HTML/문서까지가 산출이다.
3. **카드뉴스** — `sns-cardnews/SKILL.md`와 context→design→copy→build→verify 하위 스킬, `sns-cardnews/rules/`를 순서대로 읽고 10장 문안을 `02-카드뉴스-문안.md`와 `cardnews.json`(역할 순서 고정)으로 쓴다. 이미지 도구가 있으면 `node scripts/build-cardnews-html.js cardnews.json 카드뉴스/slide-preview.html "<교회 이름>"` → `node scripts/capture-cardnews-4x5.js 카드뉴스/slide-preview.html`로 1080×1350 PNG 10장을 만들고 원고와 대조한다. 없으면 문안까지 쓰고 건너뜀 안내.
4. **신앙에세이** — `faith-essay/SKILL.md`를 읽고 `03-신앙에세이.md`(상태 `draft`). 실재하지 않는 1인칭 경험을 만들지 않는다.
5. **썸네일** — `sermon-thumbnail/SKILL.md`를 읽고 `04-썸네일-브리프.md`(제목·성구·템플릿 추천)를 쓴다. 도구가 있으면 `node scripts/render_thumbnail.js --title … --scripture … [--church "<교회 이름>"] --out 썸네일`로 이미지 후보를 만든다.
6. **쇼릴** — `sermon-reel/SKILL.md`를 읽고 30초 대본 3안과 추천 1안, 원고 발화 문구 대조표를 `05-쇼릴-대본.md`와 `reel.json`으로 쓴다. 도구(ffmpeg·Pillow)가 있으면 `python3 scripts/render_reel.py --cuts reel.json --manuscript <원고> --out 쇼릴/reel.mp4`로 9:16 영상을 만든다. 서체는 동봉 Noto Sans KR가 기본이다. 음원은 권리 확인 자료가 있을 때만 넣는다.
7. **업로드 문안** — `sermon-upload/SKILL.md`를 읽고 `06-업로드-문안.md`(제목·설명·태그)를 쓴다. **실제 업로드는 이 명령이 하지 않는다.** 영상 검수와 사용자의 명시 승인 뒤에 사용자가 따로 요청할 때만 `scripts/upload_youtube.py`를 쓴다(기본 비공개).
8. **검증 기록** — `verification.md`에 단계별 산출 파일, 검증 출력, 빠진 자료, 건너뛴 단계와 `[미확인]`을 모두 적는다. 생성이 안 된 단계는 완료로 쓰지 않는다.

원천 정본은 사용자의 입력 원고다. 단계 간 내용이 충돌하면 합치지 말고 해당 문구와 행을 표시한다.
