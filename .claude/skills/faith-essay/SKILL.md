# 신앙에세이

입력은 사용자가 제공한 원고와 `00-원고지도.md`다. 한 줄기를 고르고 그 줄기에 속한 원고 행을 먼저 표시한다. 본문 상황, 오늘의 긴장, 복음의 전환, 삶의 적용을 산문으로 잇는다. 에세이는 설교 요약문도 광고문도 아니다. 독자가 자기 삶을 비추어 볼 수 있게 장면과 질문을 구체화하되 사실을 만들지 않는다.

1. 제목 2안과 중심 문장 1개. 원고의 신학적 핵심과 불일치하면 수정한다.
2. 초고: 도입의 질문 → 본문의 관찰 → 인간의 막힘 → 그리스도·복음 전환 → 한 가지 응답. 원고에 없는 성경 구절을 직인용하지 않는다.
3. 1인칭 화자는 원고에 기록된 실제 경험만 진술한다. 경험이 없으면 일반적인 독자 관찰 또는 3인칭으로 쓴다. 가상의 목회 경험·독서 경험을 실제처럼 적지 않는다.
4. 검토: 주장마다 원고 행 또는 확인 가능한 본문 근거를 붙인다. 과장, 도덕주의적 결론, 억지 감동, 반복을 고친다. `03-신앙에세이.md`의 상태는 발행 전까지 `draft`다.
5. 이미지는 사용권이 확인된 사용자 자산 또는 새로 만든 안전한 자산만 쓴다. 이미지가 없으면 텍스트 초고로 남기고 `[미확인]`을 기록한다.
