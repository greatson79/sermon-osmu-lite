# 설교 쇼릴

원천 워크플로의 대본→콘셉트·제작→검수→업로드 문안 순서를 유지한다. 원고 확정 여부부터 확인한다. 미확정이면 시안 상태를 영상·문안에 표시한다. 원고의 발화 문구만 화면에 올리고, 컷별 원문 행과 문자 대조표를 남긴다.

- 대본: 30초 후보 3안, 추천 1안. 시작의 질문, 원고의 갈등, 복음 전환, 응답, 마무리 참조가 모두 살아야 한다. 화면 문구의 글자 수와 노출 시간을 확인한다.
- 제작: `reel.json`의 각 컷 `{ "text": "원고의 연속 문구", "seconds": 4.0 }`를 작성한다. 2~12컷 총 30초. `scripts/render_reel.py --cuts reel.json --manuscript 원고.md --font 한국어폰트.ttf --out reel.mp4`로 렌더한다. 1080×1920 세로 영상, 핵심 글자는 4:5 피드 중앙 안전 구역에 둔다. 합성음·음악은 사용권과 소리 검사를 통과한 자산만 추가한다.
- 검수: ffprobe로 크기·길이·프레임률 확인, 대표 프레임 시각 검사, 원고 문구 재대조, 정지·오디오 끊김 검사. 실패하면 수정판을 새 이름으로 만든다. 독립 검수 전 영상은 초안이다.
- 업로드: `sermon-upload`로 전달. 영상 제작이 완료되어도 자동 업로드하지 않는다.

원천의 사례별 7컷 모션·합성음 매개변수·실제 계정은 공개 팩에 포함하지 않는다. 범용 렌더는 원천과 같은 PIL→ffmpeg 계열을 사용한다.
