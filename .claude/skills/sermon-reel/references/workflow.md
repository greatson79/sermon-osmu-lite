# 설교 쇼릴 30초 — 단계표

> 이 문서는 쇼릴 제작 단계를 한눈에 보는 참고 자료다. 실행은 상위 `sermon-reel/SKILL.md`와 사용자의 원고·출력 폴더를 따른다. 모든 산출은 `산출/<원고 파일명>/` 아래에 쓴다.

## 1. 단계 — 입력 → 출력 · 완료 기준
| 단계 | 입력 → 출력 | 완료 기준 |
|---|---|---|
| 1 대본 | 확정 원고 → `05-쇼릴-대본.md`(후보 3안 + 추천 1안 · 30초 타임라인 · 화면 문구 = 원고의 발화 원문) | 화면 문구 전부를 원고 원문과 글자 단위로 대조 · 초당 4.5자 이하 · 신학적 표현을 사용자가 직접 확인 |
| 2 제작 | 대본 + `scripts/render_reel.py` → `쇼릴/reel.mp4`(권리를 확인한 음원이 있으면 `_음악.mp4` · 출처·사용권은 `쇼릴/음원_기록.md`) + 대표 프레임 | 1080×1920 · 30.0초 · 화면 문구가 원문과 같음 · 정지 장면 2초 이하 · 소리가 있으면 음량 수치 기록 |
| 3 확인 | 영상 · 대표 프레임 2~3장 · ffprobe 출력 | 사용자가 영상을 직접 보고 문구·소리·길이를 확인 |
| 4 업로드 문안 | 대본 + 제목 → `06-업로드-문안.md`(제목 100자 이내 · #Shorts · 설명 · 해시태그 8~12개 · 검색 태그 15개 이내 · 빈칸 금지) | 원문·해시태그를 한 번 다시 읽어 확인 |
| 5 업로드(선택) | 확인된 영상 + 문안 → 업로드 기록 | `scripts/upload_youtube.py`를 사용자 소유 OAuth 파일로 실행 · 반환된 URL·제목·채널을 사용자가 확인 |
| 6 인스타(선택) | 무음악판 영상 | 앱 안에서 음악을 골라 올린다 |

## 2. 걸리는 시간(참고)
- 대본 약 10분 · 제작(렌더 포함) 약 50분 · 확인 약 20분 · 업로드 약 5분.

## 3. 산출 폴더 규약
`산출/<원고 파일명>/05-쇼릴-대본.md` · `쇼릴/reel.mp4` · `쇼릴/음원_기록.md`(음원을 쓸 때) · `06-업로드-문안.md`

## 4. 템플릿·도구
- `references/` — 대본·제작·문안 작성 안내.
- `scripts/render_reel.py` — 쇼릴 렌더(Pillow + ffmpeg). `scripts/crop_4x5.sh` — 4:5 피드용 크롭. `scripts/loud.sh` — 소리 크기 정리. 업로드는 `scripts/upload_youtube.py`.

## 5. 규칙 요약
- 4:5 세이프존: 마스터 9:16(1080×1920), 피드 중앙 4:5(1080×1350 · y 285~1635). 제목 바 y≥330, 자막 끝 y≤1600, 핵심 피사체도 그 안. 파생본은 ffmpeg crop으로 따로 만들고 실제 프레임을 눈으로 확인한다.
