> **공개 팩 적용**: 이 팩에서는 `scripts/render_thumbnail.js`(`--title` `--scripture` `--out`)로 렌더한다. 아래 본문의 인물·로고·옛 도구 설명은 원천 설명이며 팩에서는 위 도구만 쓴다. 인물·로고가 없으면 중립 템플릿으로 만들고, Puppeteer가 없으면 썸네일 브리프(제목·성구·템플릿 추천)까지만 쓰고 이미지 단계는 건너뜀 안내로 끝낸다.


# 주일설교 썸네일 (WK-TH)

## 위치
- 도구: `scripts/render_thumbnail.js`
- 제목·성구: 사용자 원고(`00-원고지도.md`)
- 색: `scripts/render_thumbnail.js` 안의 중립 템플릿 T01~T06

## 템플릿 6종 (로테이션)
| 코드 | 이름 | 인물 | 성격 |
|---|---|---|---|
| T01 | 딥그린 미니멀 | 없음 | 여백 지배·가장 정갈 |
| T02 | 인물 우측 | 있음 | 국내 설교 채널 표준 |
| T03 | 시네마틱 | 없음 | 빈 예배당+빛·묵직 |
| T04 | 컬러블록 | 있음 | 옐로·가장 눈에 띔 |
| T05 | 크림 아치 | 있음 | 밝고 부드러움 |
| T06 | 리빙처치풍 | 없음 | 시즌 강해용·절제 |

`--tpl auto`(기본)는 **설교계획의 주차 번호 % 6**으로 고른다 — 매주 자동으로 다른 그림이 나온다.

## 실행
```bash
cd <project-root>/src/thumbnail

node make.js                                  # 다가오는 주일 · 자동 로테이션 1장
node make.js --date 08-30                     # 특정 주일
node make.js --date 08-30 --tpl T02           # 템플릿 지정
node make.js --date 08-30 --tpl all           # 6종 전부(고르기용)
node make.js --date 08-30 --emph "받는 것"     # 강조어 옐로 처리
node make.js --date 08-30 --weekly            # weekly-works 규약 경로에 저장
node make.js --title "..." --scripture "..."  # SOT 대신 수동 입력
node make.js --tpl T06 --season "야고보서 강해 시즌1"   # T06 시즌 라벨
node make.js --date 08-30 --pose 03           # 목사님 포즈 지정
```

## 포즈 (인물 템플릿 T02·T04·T05)
| id | 종류 | 설명 |
|---|---|---|
| `arms` | 전신 | 팔짱·정면 미소 (기존 채널 썸네일에서 추출) |
| `02` | 상반신 | 손 펼침 |
| `03` | 상반신 | 양손 제스처 |
| `08` | 상반신 | 오른손 뻗음 |
| `10` | 상반신 | 손 모음 |

포즈도 **주차 번호 기준으로 자동 로테이션**된다(`--pose` 미지정 시).
전신/상반신에 따라 배치 높이·위치가 자동으로 달라진다(`templates.js`의 `FIT` 표).
추출 경로: yt-dlp(구간 다운로드) → ffmpeg(프레임) → rembg(배경 제거) → 하단 페이드 정리.

## 실행 전 필수 — 팔레트 가드
```bash
node sync_palette.js        # 정본 대조. FAIL이면 색 정본이 바뀐 것 → --fix 로 동기화
```
사본은 조용히 낡는다. 이 가드가 정본(템플릿 색 정의)과 도구의 색을 매 실행 대조한다.

## 완료 검증 (파일 존재 ≠ 통과)
```bash
node check_zone.js          # 우하단 192×108 배지 자리에 글자·얼굴·로고가 없는지 요소 좌표로 판정
```
- 판정은 픽셀 대비가 아니라 **DOM 요소 bounding box**로 한다(옷자락·배경을 침범으로 오탐하지 않게).
- 뮤테이션 검산 내장 — 금지구역에 글자를 주입해 검출되는지 매번 확인한다.
- 인물 템플릿은 **포즈별로 전수 검사**한다(현재 18개 조합).
- 축소 판독은 168×94로 줄여 육안 확인한다(유튜브 추천목록 실제 크기).

## 하드 규격
- 1280×720 · 안전영역 중앙 1100×620 · 우하단 192×108 비움(유튜브 길이배지)
- 헤드라인 최소 80px · 최대 2줄(자동 균형 분할)
- 세리프·손글씨 금지(색 규칙 §9-5) · 옐로 배경+흰 글씨 금지(§9-1) · 그린 3색 동시 금지(§9-2)

## 자산
- 이 팩은 인물 사진·배경 자산을 동봉하지 않는다. 쓰려면 사용권이 있는 자산을 사용자가 직접 준비한다.
- ★자산에 **타인 얼굴이 들어가지 않았는지** 교체 시마다 확인한다(2026-08-22 실사고: 콘서트 실황에 제3자가 찍혀 있었다)

## 미해결
- T04 옐로 대면적이 정본 면적 규칙(60:30:10)과 충돌 — 사용자 판단 대기.
- 상반신 포즈 4종이 모두 **같은 영상(같은 옷·같은 배경 조명)**에서 나왔다. 다른 주차 영상에서 추가 추출하면 다양성이 더 는다.
- 폰트가 Pretendard(정본 지정은 Noto Sans KR). 헤드리스 로딩 문제로 대체 중.

## 공개 팩 렌더 적용

기관 인물·로고·설교계획 파일에 묶인 원천의 옛 썸네일 도구는 이 팩에 없고 쓰지 않는다. 사용자 원고의 제목·본문 참조를 받아 `scripts/render_thumbnail.js --title '<제목>' --scripture '<본문>' --out '<출력폴더>' --tpl all`을 실행한다. Puppeteer로 중립 기본 템플릿 6종 1280×720 PNG를 만든 뒤 각 이미지의 글자 잘림·대비·본문 표기를 실물 검사한다. 사용자 인물·로고는 명시 제공 시에만 추가한다.
