# 업로드

1. 원고·최종 영상과 일치하는 제목(100자 이내), 설명, 해시태그 8~12개, 검색 태그 15개 이내를 `upload-draft.md`에 쓴다. 링크를 넣으면 응답 코드를 실제 확인한다.
2. 영상 자체의 길이·크기·자막·음원권·가시 문구를 검수한다. 사용자 소유 채널과 공개 범위를 명시적으로 확인한다.
3. 외부 업로드는 사용자의 별도 명시 승인 뒤에만 실행한다. `scripts/upload_youtube.py`는 `--client-json`, `--token-json`, `--file`, `--title`, `--privacy`, `--confirm-upload`를 요구하고 기본 공개 범위는 private다. OAuth 파일은 저장소 밖 사용자 경로에 둔다.
4. 실행했다면 반환 ID·URL·실측 시각과 공개 범위를 기록하고 실제 링크를 확인한다. 실행하지 않았으면 `[미확인] 업로드 미실행`으로 남긴다. 업로드 준비를 완료로 바꾸지 않는다.
