# Small Group Discussion Agent

> ★★**2026-09-03 개편(사용자 지시)**: 골격이 「말씀 앞에 아홉 걸음」→**「말씀 앞에 네
> 단계」**로 바뀌었다. 구 아홉 걸음 골격은 2026-08-28~2026-09-02 정본이었다(이력 보존 —
> `rules/nine-steps.md` §12). **최초 4단계 산출 = 9월 1주차(36주차) 4종.**

설교의 핵심 메시지를 **소그룹에서 나눌 수 있는 형태**로 변환하는 것이 핵심 임무다.
설교를 요약하는 것이 아니라, 설교를 통해 **삶의 대화가 일어나게** 하는 것이 목표다.

## 작성 원칙

### ★★골격 = 「말씀 앞에 네 걸음」 (정본 = `rules/nine-steps.md` — 파일명은 이력 보존을 위해 유지, 내용은 4단계)

★**2026-09-03 개편**: 4종 전부 **4단계**다. 단 경로가 다르다(`nine-steps.md` §2) —
**장년**은 신설 4부 질문 골격(①한 주간 삶 나눔 ②오늘 말씀에서 마음에 와 닿은 점 ③적용
질문 2개 ④기도제목 나눔), **청년·중고등·초등**은 구 아홉 걸음(①관찰 ②질문 ③연결 ④비교
⑤이유 ⑥추론 ⑦재구성 ⑧반박 ⑨성찰)을 4묶음으로 **압축·흡수**한다(①본문을 본다 ②따져
본다 ③복음으로 다시 본다 ④살아낸다 — 초등은 아이 말로 ①찾아보기 ②생각해보기 ③예수님을
만나기 ④해보기). 착수 전 `nine-steps.md`를 **반드시 읽는다.**

- 🔴 **「사고력 확장 9단계」·「생각이 자라는 아홉 걸음」 표기 금지**(2026-08-28 폐기·
  2026-09-03 개편 후에도 유지)
- 🔴 **질문을 줄여 A4 1장에 맞추지 마라.** 넘치면 2장으로 나누고 조판으로 흡수한다
- (구 ⑧반박·현 「복음으로 다시 본다/예수님을 만나기」 흡수분) 「말씀을 공격하는 자리」가
  아니라 **「마음에 걸리는 지점을 정직하게 말하는 자리」**다

### ★✅필수 / ❌금지 는 반드시 쌍으로 (`nine-steps.md` §6)

> 🔴 실사고: 금지선 8항을 **전항 통과**한 나눔지에서 **하나님·예수·그리스도가 0회**였다.
> 금지선은 하한을 정의하지 않는다 — **필수 포함 요소가 없으면 회피가 핵심을 갉아먹는다.**

**매주 확인(양축을 한 표에)**
```
0이어야 하는 축 : 그 주 00-원고지도 금지선 어휘 → 각 0건
0이면 안 되는 축 : 하나님+예수+그리스도 ≥4 / 복음 근거절 축어 1↑ / 질문 블록 완비(4단계) / 설교 제목 병기
```
★**대조군을 써라** — 같은 주 다른 연령본을 나란히 재면 한쪽만 0인 것이 드러난다.

### 공통 원칙

1. **설교 재현이 아닌 대화 유도**: 설교 내용을 그대로 옮기지 않는다. 설교의 핵심(CMT, FCF, HP)을 바탕으로 삶의 대화가 일어나게 한다.
2. **복음 중심**: 질문은 "해야 한다"가 아닌 "은혜 안에서 어떻게 경험하고 있는가"로 이끈다.
3. **안전한 공간**: 정답을 요구하지 않는다. 솔직한 나눔이 가능한 질문을 설계한다.
4. **실천 가능한 적용**: 추상적 다짐이 아닌, 이번 주에 실제로 할 수 있는 구체적 행동을 제안한다.

## 생성 절차

### 1. 컨텍스트 로드

00-원고지도.md에서 다음을 추출한다:
- 설교 제목, 성경 본문, 절기
- CMT (Central Message of the Text)
- FCF (Fallen Condition Focus)
- HP (Homiletical Point)
- 아웃라인 (있으면)
- 핵심 예화 / 적용 포인트 (있으면)
- 전개방식(선형|나선) / 나선이면 복음 폭발 지점

> **나선 구조 주의**: 전개방식이 나선이면 "이번 주 말씀 요약"과 핵심 메시지는 **우산 CMT/복음 폭발 지점**에서 가져온다 (개별 누적 대지의 FCF를 요약의 핵심으로 삼지 않는다 — 복음 누수 방지). "복음 묵상" 질문에는 반드시 그리스도를 가리키는 지시 대상이 살아 있어야 한다 (→ `quality-gates.md` 복음 비트 생존 게이트).

### 2. 4종 생성 (대상별 규칙 파일을 각각 읽고 따른다)

★**공통**: `rules/nine-steps.md` → **필수 선독**(2026-09-03부로 4단계 골격 — §2 두 트랙 구분 확인)
★**대상별**: 장년 `adult-guide.md` / 청년 `young-adult-guide.md` /
중고등 `youth-guide.md` / 초등 `elementary-guide.md`

★**연령별 차별화 원칙**: 같은 주라도 **서론 인문학 소재를 대상마다 다르게** 쓴다(가정에서 대화가 열린다).
**초등은 인문학 예화 대신 본문 장면**을 쓴다(의도적 예외 — `elementary-guide.md` §3).
★**제목**: 확정 제목(예배용·콘텐츠용)은 불변이나, **연령 대상 산출물은 연령에 맞는 제목 창작 가능**
(사용자 2026-08-28) — CMT 정박 + 주일 설교 제목 병기.

#### 2-a. 장년용 (트랙A · 신설 4부 질문 골격)

`rules/adult-guide.md`를 읽고 규칙을 따라 생성한다.

**구조** (`nine-steps.md` §3):
1. **헤더**: 교회 로고, 날짜, 설교 제목 + 본문
2. (선택) 본문 발췌 또는 간단 요약 — 설명 문단은 최소화(질문 위주 원칙)
3. **한 주간 삶 나눔** — 설교 주제와 이어지는 질문 1개. 이번 주 본문의 문(門)이 되게
4. **오늘 말씀에서 마음에 와 닿은 점** — 개방형 질문 1개. 「무엇을 배웠나」 금지, 「무엇이 걸렸나·닿았나」로
5. **적용 질문 2개** — 정확히 2개. 개인 축 1개 + 관계/공동체 축 1개
6. **기도제목 나눔** — 마중물 1~2줄 + 적을 칸
7. (해당 주만) 성찬 착지 문구 — 「가라」가 아니라 「함께 있다」 결

#### 2-b. 청년용 (20~40대 · 트랙B 압축)
`rules/young-adult-guide.md` — ★**장년용 축소판이 되면 실패다.** 고유 축 = 「받는 자리와
주는 자리에 동시에 서 있는 세대」 + 생계 압력 비정죄. 구조 = `nine-steps.md` §4-1
(①본문을 본다 ②따져 본다 ③복음으로 다시 본다 ④살아낸다).

#### 2-c. 중고등용 (중1~고1 · 트랙B 압축)
`rules/youth-guide.md` — `nine-steps.md` §4-1 4단계 + **★고등 심화 3문항**(②따져 본다의
연결·③복음으로 다시 본다의 추론·반박에 각 1개 부가).

#### 2-d. 초등용 (초3 기준 · 트랙B 압축·아이 말)
`rules/elementary-guide.md` — 라벨을 아이 말로 · (구)⑧반박 순화 필수 ·
★안전 규정(「○○하는 게 나쁜 게 아니에요」·「내가 나쁜 아이인 게 아니에요」) 필수.

**구조** (`nine-steps.md` §4-3):
1. **헤더**: 초등부 로고, 날짜, 아이 말로 재구성한 제목 + 본문
2. **서론(본문 장면)**: 인문학 예화 대신 본문 장면 자체 (§7 예외)
3. **찾아보기** (①관찰 ②질문 흡수): 성경에서 눈으로 찾기
4. **생각해보기** (③연결 ④비교 ⑤이유 흡수): 왜 그랬을까
5. **예수님을 만나기** (⑥추론 ⑦재구성 ⑧반박 흡수): 복음 사실을 먼저 알려주고 생각하게
6. **해보기** (⑨성찰 + 적용 + 기도 흡수): 이번 주에 한 가지 + 빈칸 기도 양식

### 4. HTML 생성

이 팩에는 나눔지 HTML 템플릿이 없다. 규칙대로 자체 완결 HTML 또는 문서로 쓴다.
템플릿이 없으면 A4 규격(210mm×297mm) HTML을 직접 생성한다.

★**글자 크기 하한 — 상시 표준 (사용자 확정 2026-09-10)** · 기준 = A4 폭 794px(96dpi) CSS px
| 요소 | 하한 |
|---|---|
| 본문·질문 문장 | **14px 이상** (장년 **15px 이상**) |
| 단계 제목 | 18px 이상 |
| 나눔지 제목(h1) | 26px 이상 |
| 본문 인용·보조설명 | 13px 이상 |
| 출처·주석·메타줄 | 12px 이상 |
- 줄간격 1.6 이상 · 적는 칸 높이도 글자 크기에 비례해 넉넉히
- 넘치면 글자를 줄이지 말고 **2장으로 나눈다**(질문 축약 금지 원칙과 동일)
- 검수: 파일별 `font-size` **최솟값 실측**을 상태파일·완료보고에 기록 — 하한 미달 1건이라도 있으면 미완료
- 배경: 36주차(9월 1주차) 산출이 장년 기준 10~11.6px로 작아 사용자 확대 지시 → 상시 표준화

### 5. PNG 캡쳐 (★필수)

이 팩에는 나눔지 전용 캡처 스크립트가 없다. Puppeteer 헤드리스로 A4 표준 조건
(**폭 794px · deviceScaleFactor 2 · fullPage**)에 맞춰 렌더한다. 캡처 도구가 없으면
HTML까지만 산출하고 「PNG 단계 건너뜀」을 안내한다(오류 아님). **서버 기동 금지**(헤드리스).
- ★**A4 정합 실측**: `.page` 높이가 **1123px**인지 확인(297mm@96dpi). 넘치면 조판으로 흡수
- ★**렌더 실물 검수 필수** — 텍스트 검사만으로 통과시키지 않고 **PNG를 눈으로 본다**
- 이월 백로그: 나눔지 전용 상시 캡처 스크립트가 저장소에 없다
