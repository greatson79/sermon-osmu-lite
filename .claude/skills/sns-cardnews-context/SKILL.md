# Context Extractor (하위 스킬)

## 추출 원칙

1. **전문 정독 후 추출** — 서두·결론만 보고 CMT를 추정하지 않는다.
2. **근거 동반 의무** — 모든 필드에 원고 인용 1줄을 붙인다. 인용할 수 없는 필드는
   추출하지 않는다(빈 필드 + 사유 기재).
3. **HP는 창작 금지** — 원고에 복음 전환이 없으면 만들어 넣지 않는다. "부재"로 보고해
   대표 스킬이 설교자에게 확인하게 한다. (스킬이 설교자의 신학을 대신 쓰면 안 된다.)
4. **본문 표기 정확성** — 성경 책명·장·절은 원고 표기를 따르되, 원고가 모호하면
   본문 인용 구절로 역추적해 확정하고 [역추적] 표기를 남긴다.

## 출력 형식

```markdown
# Sermon Context
- 설교 제목: ...
- 콘텐츠용 제목(제안): ...
- 성경 본문: 막 10:35-45
- CMT: ...
- FCF: ...
- HP: ...
- 예화: ...

## 추출 근거
- CMT ← "원고 인용..." (위치)
- FCF ← "..."
- HP ← "..." (또는: 부재 — 명시적 복음 전환을 찾지 못함)
```
