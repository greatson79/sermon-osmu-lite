# Copy Writer (하위 스킬)

## 선행 조건 — 외부 URL 포함 시 (fail-closed, 2026-08-21 배선)

캡션·첫댓글에 블로그 등 외부 URL을 넣어야 하는 경우, **호출자(대표 스킬)의 브리프에 그
URL의 실측 200 로그(도구 실행 결과+시각, 사람 진술 아님)가 있어야만** 이 스킬이
`caption-instagram.txt`(또는 첫댓글이 포함된 캡션 파일)를 산출한다. 로그가 없으면:
1. 캡션·첫댓글 파일을 **산출하지 않는다**(빈 파일도 만들지 않는다 — 만들면 하류에서
   `{{BLOG_URL}}` 같은 플레이스홀더가 실측 없이 확정 URL로 오인될 위험이 있다).
2. `slides.md`(URL을 포함하지 않는 부분)는 정상 진행 가능.
3. 대표 스킬에 "A6 게이트: URL 200 로그 없음 — 캡션 보류"로 반환한다.

URL이 아예 없는 산출물(교회 주간 카드뉴스 등 외부 링크 미포함)은 이 조건이 적용되지 않는다.

## 출력

| 산출물 | 파일 |
|--------|------|
| 슬라이드 텍스트+디자인 지시 병기 | `slides.md` |
| 인스타그램 캡션 | `caption-instagram.txt` |
| 카카오톡 메시지 | `message-kakao.txt` |
| 표지 제목 2안 | 대표 스킬에 반환(택1 후 slides.md 확정) |

## 10장 구조 (규격 정본)

1 표지 / 2 공감·질문 / 3 문제 심화 / 4 본문 전환 / 5 CMT / **6 복음 적용(HP·불가침)** /
7 인용구 / 8 적용·실천 / 9 초대·CTA / 10 마무리(로고·교회 정보)

- 슬라이드 6: "그러나 하나님은 ~ 하셨습니다" / "그래서 우리는 ~ 할 수 있습니다" 류의
  **그리스도를 가리키는 복음 전환** 필수. 도덕 교훈으로 마감 금지.
- 슬라이드 10: 교회명·예배 시간·SNS 계정은 사용자가 준 교회 정보(`원고/교회이름.txt`)만 사용(없으면 비움).

## 톤 가이드

| 요소 | 톤 |
|------|-----|
| 표지 | 깔끔·절제·품격 |
| 공감 | 따뜻하고 솔직 |
| 핵심 메시지 | 경건하되 접근 가능 |
| 적용/초대 | 친근하고 환영 |
| 인용구 | 울림·공유 욕구 |

과장·거짓 확신 표현 금지(예: 근거 없는 "반드시 ~됩니다" 류의 번영복음적 단정).

## slides.md 형식

```markdown
## 슬라이드 N: {역할}
**텍스트:** (실제 들어갈 문구)
**디자인 지시:** (design-brief.md 해당 장 지시 요약)
```
