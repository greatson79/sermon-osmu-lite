# Verifier (하위 스킬 · 독립 검증 전담)

작성자와 검증자는 분리된다. 이 스킬은 산출물을 **만들지 않는다** — 판정만 한다.
수정 지시가 필요하면 "무엇이 왜 실패했는지"를 기재해 대표 스킬이 담당 하위 스킬에
되돌리게 한다.

## 5축 검증

| 축 | 방법 | FAIL 조건 |
|----|------|----------|
| 1. 성경 인용 | 장절 단위 원문 대조(웹/로컬 자료) | 오인용·존재하지 않는 구절·왜곡 |
| 2. 복음 비트 | 복음 적용 장 문장 실재 확인 | 그리스도 지시 문장 부재·도덕 교훈만 |
| 3. 규격 | 도구 실측(개수·해상도) | PNG≠10·해상도≠1080×1350(×스케일 배수) |
| 4. 플레이스홀더·금지선 | 전 산출물 스캔 | `{변수}` 잔존·이모지 아이콘·텍스트 로고 |
| 5. 과장·거짓 확신 | 문장 단위 검토 | 근거 없는 단정·원고에 없는 사실 주장 |

## 판정 규율

- **근거는 실제 콘텐츠 행만** — 산출물이 "금지선을 준수했다"고 적은 자기 선언문은
  준수의 증거가 아니다(순환논증 금지).
- **검증 불가 ≠ PASS** — 대조할 수 없었던 항목은 "검증 불가 + 사유 + 훑은 범위"로
  정직 기재한다. 검증 불가 항목이 있으면 종합 판정에 그 사실을 명시한다.
- **부재 판정은 방법 명시** — "문제 없음"이라 쓰려면 무엇을 어떻게 훑었는지 쓴다.

## 출력: verify-report.md

```markdown
# 검증 보고
- 대상: (파일 목록 + 검증 시점)
- 축별 판정: 1~5 각 PASS/FAIL/검증불가 + 근거(파일:행 인용)
- 종합: PASS / FAIL(재작업 지시 대상 스킬 명시)
```
