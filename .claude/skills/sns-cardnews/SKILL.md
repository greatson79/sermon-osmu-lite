# 카드뉴스

이 폴더의 `sns-cardnews_SKILL.md`를 전문으로 읽고 context→design→copy→build→verify를 순서대로 수행한다. 기관 고정 로고·색상 대신 사용자 설정 또는 중립 기본을 쓴다. `scripts/build-cardnews-html.js`로 HTML, `scripts/capture-cardnews-4x5.js`로 PNG 10장을 만든다. 4:5, 1080×1350, 여섯 번째 복음 전환, 원고·성경 인용 검증을 지킨다. 실제 PNG를 열어 잘림과 문구를 확인한다.
